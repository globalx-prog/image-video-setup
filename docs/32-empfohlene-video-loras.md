## 🛠️ Wie binde ich ein neues LoRA in ComfyUI ein?

1. **Download:** Legen Sie die heruntergeladene `.safetensors`-Datei in folgendem Ordner ab:
   ```bash
   /home/clemi/Projekte/LLM/image-video-setup/ComfyUI/models/loras/
   ```

2. **In ComfyUI einhängen:**
   - Fügen Sie eine `LoraLoaderModelOnly` Node zwischen dem UNET-Loader (Node 1) und dem Modell-Switch (Node 6) ein.
   - Stellen Sie die Stärke (`strength_model`) auf den oben empfohlenen Wert ein (typisch `0.65` bis `0.80`).

3. **Im Prompt aufrufen:**
   - Fügen Sie die oben genannten Trigger-Keywords in die `action`- oder `style`-Zeile Ihres Drehbuchs ein.
